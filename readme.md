# displayAnything

A small web app for creating and storing notes as links.

## features
- creating notes as copyable links using encryption and decryption
- reading them on the same page
- links get absurdly long on bigger notes (so try to keep in that 50-250 characters)

## installation and usage
You can use displayAnything on [https://adamkurbiel.github.io/displayanything](its' github page) because it's client-sided.
Although if You feel unsatisfied, You can always download it and run by yourself.
```bash
git clone https://github.com/adamkurbiel/displayanything.git
cd displayanything
```
then run it on a live server.
